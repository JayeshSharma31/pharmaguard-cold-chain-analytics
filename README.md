# PharmaGuard — Pharmaceutical Cold-Chain Intelligence

### Pharmaceutical Cold-Chain Compliance, Risk & Medicine Wastage Intelligence

An interactive **Power BI Business Intelligence solution** designed to analyze pharmaceutical cold-chain compliance, temperature excursions, shipment delays, shelf-life risks, medicine wastage, incidents, and logistics performance.

## Project Overview

Pharmaceutical products can be sensitive to temperature fluctuations and delivery delays. Monitoring cold-chain conditions and identifying high-risk shipments are important for maintaining product quality and reducing potential medicine wastage.

**PharmaGuard** brings shipment, sensor, product, incident, warehouse, route, weather, and carrier information together in an interactive Power BI report.

**Project scope:** 2023–2025

## Business Objectives

- Monitor cold-chain temperature compliance.
- Identify temperature excursions and high-risk shipments.
- Analyze shelf-life risk and potential medicine wastage.
- Investigate delivery delays and logistics performance.
- Examine incident severity and distribution.
- Compare warehouse and route performance.
- Support data-driven operational monitoring and investigation.

## Dashboard Pages

The report includes a project overview, six analytical dashboards, a consolidated insights page, and a shipment investigation drill-through.

| Shelf-Life & Wastage | Analyzes expiry risk and products requiring attention |
| Logistics Analysis | Investigates delivery delays and logistics performance |
| Incident Analysis | Examines incident volume and severity |
| Warehouse & Route Analysis | Supports comparisons across warehouses and routes |
| Key Insights & Recommendations | Consolidates findings into actionable recommendations |

## Interactivity

The report includes navigation between pages, slicers, reset buttons, conditional formatting, and drill-through functionality to support both summary-level and detailed investigation.

## Business Value

PharmaGuard demonstrates how Power BI can bring operational data into a unified reporting solution to help stakeholders identify risks, investigate exceptions, monitor logistics performance, and prioritize follow-up actions.

The report is designed to support decision-making; it does not independently establish medicine safety or replace pharmaceutical quality-control procedures.

## How to Use

1. Download the `.pbix` file from this repository, when available.
2. Open it in Power BI Desktop.
3. If prompted, configure the appropriate data sources and paths.
4. Refresh the data if the source files are available.
5. Explore the report using its navigation controls, slicers, and drill-through pages.

Dataset availability and refresh requirements depend on the original data sources and sharing permissions.
